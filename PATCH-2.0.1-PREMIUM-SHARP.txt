POČITADLO NÁVŠTĚV — 1x CLOUDFLARE NASTAVENÍ
1. Cloudflare > Storage & Databases > KV > Create namespace
2. Název např. RYVEX_VISITORS
3. Workers & Pages > ryvex-website > Settings > Bindings
4. Add binding > KV namespace
5. Variable name MUSÍ být přesně: RYVEX_VISITORS
6. Vyber vytvořený namespace a Save
7. Redeploy posledního deploymentu nebo udělej nový commit

Bez KV bindingu web normálně funguje a počitadlo se pouze nezobrazí.
Počítadlo ukládá jen náhodné anonymní UUID prohlížeče. Nezapisuje IP, Discord ID, email ani fingerprint.
